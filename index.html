02PRINCIPLES / 设计信条

我不太相信「灵感」，
更相信把问题拆开。

下面四条是我做每个项目时反复回到的检查点，也是这个网站本身的制作标准。

  1. 01先立结构，再谈风格。STRUCTURE FIRST
  2. 02颜色不是装饰，是权重。COLOR IS HIERARCHY
  3. 03动效只用来解释层级。MOTION EXPLAINS
  4. 04好看是门槛，能读懂才是结果。READABLE, THEN BEAUTIFUL

05WHO IS BEHIND THIS

关于我 / ABOUT

一句话版本：把信息理清楚，再把画面做舒服。

WANG ZHENGQING · VISUAL DESIGNER

我在兰州做设计，
从平面做到界面和三维。

设计不是把东西摆漂亮，而是替别人做决定：决定他先看到什么、相信什么、下一步做什么。所以我习惯从结构开始做，再谈风格。

我在兰州读完艺术设计专业，现在把大部分时间花在三件事上：把信息理清楚、把界面做舒服、把三维画面调到自己愿意多看两眼。
